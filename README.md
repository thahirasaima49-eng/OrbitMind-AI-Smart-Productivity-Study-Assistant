
# OrbitMind AI – Smart Productivity & Study Assistant

## About The Project
OrbitMind AI is a Smart Productivity & Study Assistant
designed to help users organize their study activities
and improve productivity.

This project is developed collaboratively by a team
of four members as an academic group project.

## Project Objectives
- Improve study management
- Organize productivity activities
- Provide a smart study assistance experience

## Key Features
- Create and Categorize Tasks
- Study Session Planning
- Deadline Tracking
- Workload Pattern Analysis
- AI-Based Productivity Suggestions
- Smart Study Recommendations
- Natural Language Task Input
- Quick Study Summaries and Notes
- Task Breakdown
- Study Consistency Tracking
  
## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MySQL Workbench
- Visual Studio Code
- Git & GitHub
- OpenAI API / Gemini API / Grok API
- Render / Railway / Vercel Postman
